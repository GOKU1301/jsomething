# Main Project

This is a multi-service repository (monorepo) for the Main Project.

## Project Structure

- `jayprint/`: A microservice for digital printing management (Node.js/React).
- `main-backend/`: (Future) The main backend logic for the project (Spring Boot).

## Getting Started

### JayPrint Service
To run the JayPrint service:
1. Go to `jayprint/backend` and run `npm run dev`.
2. Go to `jayprint/frontend` and run `npm start`.
